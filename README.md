# 🌸 Iris Flower Species Predictor

An interactive Machine Learning project that predicts Iris flower species using Streamlit and Scikit-learn.

---

# 🚀 Features

- Predicts Iris flower species
- Interactive Streamlit sliders
- Real-time predictions
- Clean UI Dashboard
- Machine Learning integration

---

# 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

---

# 📊 Machine Learning Workflow

1. Data Collection
2. Data Preprocessing
3. Model Training
4. Species Prediction
5. Streamlit Dashboard Integration

---

# 📂 Project Structure

```bash
iris-flower-species-predictor/
│── app.py
│── iris.csv
│── iris_logic_model.pkl
│── requirements.txt
│── README.md
```

---

# ▶️ Run the Project

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Streamlit App

```bash
python -m streamlit run app.py
```
